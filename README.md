# RebateProof

RebateProof checks redacted purchase records against a sponsor's published rebate policy. It records clause-level decisions on GenLayer StudioNet (61999). The illustrative Northline campaign distinguishes AER-2400-PRO from AER-2400.

Install with `npm ci`, run `npm test`, and start the dashboard with `npm run dev`. The production build is `npm run build`.
